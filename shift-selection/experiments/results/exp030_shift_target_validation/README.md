# exp030：シフト対象の選定と診断手順全体の検証（GridWorld 10 次元）

## 目的
主張 2（「Δ で選んだ特徴をシフトすれば、不変性テストで問題を見つけられる」）は、これまで同じ介入（特徴の置換）で確かめていた。Δ は置換による性能低下そのものなので、この確認は循環している。この実験では、選定（exp029 の Δ・SHAP）と評価（環境側の分布シフト）を独立にする。そのうえで、Δ・SHAP・ランダムを同じ条件で比べ、主張 1 と主張 2 をつないだ診断手順全体も評価する。事前登録は `experiments/plans/exp030_shift_target_validation.md` にある。研究の問い、主な仮説、判定条件は実行前に固定しており、結果を見てから変えていない。

## 設定
- exp029 の 120 run（30 シード × `spurious_p` = 0.0 / 0.1 / 0.2 / 0.3）を同じ順序で再学習した。120/120 run で exp029 と一致した（AA(train)、J_S(train)、J_oracle(train)）。選定には exp029 の `results.csv` にある Δ と SHAP の値を使った。
- シフトは環境側で、1 特徴につき 2 種類、合計 20 条件（`none` を除く）。
  - c：反転（reversed）／ランダム化（random）
  - noise_i：U(0, 0.5)（low）／U(0.5, 1)（high）
  - agent_x・agent_y：開始位置を {0,1}（start_lo）／{3,4}（start_hi）に制限
- 正解の評価（gt）は 500 エピソード、手順用の再テスト（pl）は 200 エピソード。それぞれ別のエピソード seed を使い、条件の間では乱数を共通にした。
- AA は論文 A と同じ方法で、学習時の評価状態の該当列を変換して計算した。開始位置のシフトは状態の変換で表せないので、ロールアウトで得た状態を使った。
- スクリプトは `experiments/run_shift_target_validation.py`、集計は `experiments/compute_stats_shift_target.py`（結果は `stats.txt`）、設定は `experiments/configs/exp030_shift_target_validation.yaml`。
- 実行時間：**3 時間 07 分 54 秒**（120 run、4 並列。1 run あたり、p=0 は約 200 秒、p=0.3 は約 480 秒）。

正解集合（特徴は、2 種類のシフトのどちらかで条件を満たせば正解に入る）：
- H_J：J_S(shift) < 0.8 · J_S(train)。選定の評価の主な正解。
- H_inv：AA(shift) > 0.9 かつ H_J の条件。論文 A の判定基準。
- J_S(train) ≤ 0 の run（3 件）は判定から除いた。

## 主な仮説の結果（片側、Holm 補正、有意水準 0.05）

| 仮説 | 観測 | ランダムの期待値 | Holm 補正後 p | 判定 |
|---|---|---|---|---|
| H1：Δ（サロゲート）の hit@1（正解 = H_J）はランダムを上回る | 87/117 | 21.6/117 | 3.0e-44 | 支持 |
| H2：Δ（サロゲート）による診断手順全体の成功はランダムを上回る | 11/120 | 1.4/120 | 1.2e-09 | 支持 |

どちらも事前登録した基準で支持された。ただし、効果の範囲と大きさには次の制約がある。

## 選定（正解 = H_J、hit@1）

| p | Δ（サロゲート） | SHAP（サロゲート） | Δ（オラクル） | SHAP（オラクル） | ランダム（期待値） |
|---|---|---|---|---|---|
| 0.0 | 30/30 | 30/30 | 30/30 | 30/30 | 3.0 |
| 0.1 | 29/30 | 10/30 | 30/30 | 8/30 | 4.2 |
| 0.2 | 18/29 | 7/29 | 27/29 | 11/29 | 6.0 |
| 0.3 | 10/28 | 12/28 | 24/28 | 20/28 | 8.4 |
| 全体 | 87/117（74%） | 59/117（50%） | 111/117（95%） | 69/117（59%） | 21.6 |

読み取れること：
1. **Δ（サロゲート）がランダムを上回るのは p ≤ 0.2 だけである。** p = 0.3 では 10/28 で、期待値の 8.4 とほぼ同じである（p ごとの記述的な検定では p = 0.31。事前登録した検定ではない）。H1 の支持は p ≤ 0.2 の run によるものである。
2. **Δ（サロゲート）の当たり 87 件のうち 85 件は c である。** H_J には c が全 117 run で入る。したがって、この評価は実質的に「シフトで性能が崩れる c を top-1 に選べるか」を見ている。
3. **同じモデル上では、Δ が SHAP より当たる。** これは p = 0.1・0.2 で成り立つ。McNemar 検定の結果は次のとおり（全体、b = Δ だけ当たり、c = SHAP だけ当たり）。
   - サロゲート：b = 36、c = 8、p < 0.0001
   - オラクル：b = 45、c = 3、p < 0.0001

   p = 0.3 では、どちらのモデルでも有意差はない。
4. **Δ のサロゲートの外れは、サロゲートの忠実度による。** p ≥ 0.2 では、Δ（オラクル）がサロゲートより明らかに当たる（全体で b = 1、c = 25、p < 0.0001）。サロゲートの Δ が外れた 30 run では、top-1 は noise_0・noise_2・agent_x・agent_y のどれかである。その特徴をシフトしたときの低下は 0.05 以下だった。
5. Δ とシフトによる低下の順位相関（run ごとの Spearman、中央値）は、p が大きくなるにつれて下がる。値は p = 0.0 から 0.3 の順に +0.65、+0.50、+0.17、+0.04 である。置換による低下で分布シフトによる低下を予測できるのは、サロゲートが方策をよく近似している範囲に限られる。

## 診断手順全体（段階 1 あり、論文 A の手順どおり、正解 = H_inv）

各 run を次の 5 つに分けた。段階 1 で終了／段階 2 で検出／段階 2 で誤警告／段階 2 で見逃し／段階 2 で非検出（正解集合が空）。

| 選定法 | 段階1で終了 | 検出 | 誤警告 | 見逃し | 非検出（正解集合が空） | 検出率（全 run） | 検出率（段階1 通過） | 誤警告率（段階1 通過） |
|---|---|---|---|---|---|---|---|---|
| Δ（サロゲート） | 69 | 11 | 2 | 3 | 35 | 11/120（9%） | 11/51（22%） | 2/51（4%） |
| SHAP（サロゲート） | 69 | 8 | 4 | 6 | 33 | 8/120（7%） | 8/51（16%） | 4/51（8%） |
| Δ（オラクル） | 69 | 11 | 2 | 3 | 35 | 11/120（9%） | 11/51（22%） | 2/51（4%） |
| SHAP（オラクル） | 69 | 8 | 3 | 6 | 34 | 8/120（7%） | 8/51（16%） | 3/51（6%） |
| ランダム（期待値） | 69 | 1.4 | 0.4 | 12.6 | 36.6 | 1.4/120 | 1.4/51 | 0.4/51 |

誤警告率の分母は段階 1 を通過した 51 run で、H_inv が空の 37 run も含む。p ごとの表は `stats.txt` にある。

読み取れること：
1. **H2 は支持されたが、検出率の絶対値は低い（全 run の 9%）。** 検出は p = 0.0（5 件）と p = 0.1（6 件）だけである。p = 0.2・0.3 では 0 件だった。
2. **妨げになっているのは選定ではなく、論文 A の判定条件である。**
   - 段階 1（AA(train) ≥ 0.9）で 69/120 run が終わる。p = 0.3 では全 30 run、p = 0.2 では 23/30 run である。
   - 段階 1 を通過した 51 run のうち、37 run では H_inv が空になる。c をシフトすると方策の性能は崩れる（p = 0 で J_S は +0.97 から −1.00）が、AA も 0.9 を割る（c 反転時の平均は p = 0 で 0.85、p = 0.1 で 0.80）。
   - オラクル自身も c に依存している（c 反転時の J_O は −1.00）ので、シフト下ではサロゲートとオラクルの一致も下がる。
3. **補足（事前登録では主な結果としていない）。** 判定から AA の条件を外して H_J を正解にすると、段階 1 を通過した run での検出率は次のとおりだった。
   - Δ（サロゲート）：48/51（94%）
   - SHAP（サロゲート）：31/51（61%）
   - ランダムの期待値：5.5/51

   選定そのものは、段階 1 を通過した run ではほぼ機能している。
4. 誤警告は少ない（Δ（サロゲート）で 2/51）。この 2 件は p = 0 の run（seed 12・18）で起きている。c をランダム化したときの AA が、pl（200 エピソード）では 0.9 をわずかに越え（0.900・0.903）、gt（500 エピソード）では越えなかった（0.887・0.895）。閾値の近くで起きた判定の揺れである。

## 特徴別・シフト条件別の性能低下

条件ごとの数値は `stats.txt` の「特徴別・シフト条件別の性能低下」にある。シフトの種類による偏りは次のとおりである。

- **c のシフトは常に性能を崩す。** 反転でもランダム化でも、全 117 run で H_J の条件を満たした。平均の低下は反転で +1.52、ランダム化で +0.70 である。H_inv に入ったのは 12 run で、すべてランダム化による（ランダム化だけで成り立ったのが 6 run、両方で成り立ったのが 6 run）。反転は AA を大きく下げるので、反転だけで H_inv に入った run はない。
- **開始位置とノイズのシフトは、平均ではほとんど性能を下げない。** 平均の低下は −0.03 から +0.04 の範囲である。H_J に入るのは、p ≥ 0.1、主に p = 0.2・0.3 の run で、J_S(train) が小さい（中央値 0.32）ため、小さな低下でも比の閾値を越えるからである。
  - これら c 以外の H_J の要素 99 件のうち 80 件は、独立したエピソードを使う pl でも H_J に入った。大半は推定のばらつきではなく、実際の低下である。
  - 件数が多い条件は agent_y の start_hi（13 run）と noise_3 の high（12 run）である。特定の条件に大きく偏ってはいない。
- **H_inv に入った特徴は、c が 12 run、ノイズ特徴が計 7 run（p = 0.1 で 5、p = 0.2 で 2）で、開始位置は 0 run だった。**

## 結論
- 主張 2 の選定の部分は、置換と独立な分布シフトでも確かめられた。範囲は p ≤ 0.2 で、ここでは Δ がランダムと SHAP を上回る。p = 0.3 では、サロゲートの Δ はランダムと区別できない。オラクルの Δ では 24/28 当たるので、限界はサロゲートの忠実度にある。
- 主張 1 と主張 2 をつないだ手順全体は、ランダムより多く検出する。しかし、論文 A の判定条件（段階 1 の AA(train) ≥ 0.9 と、シフト下の AA > 0.9）のもとでは、検出率は全 run の 9% にとどまる。この 10 次元の設定では、スプリアス特徴をシフトすると AA も 0.9 を割るため、主張 1 の判定条件はほとんど成り立たない。この点は、主張 1 の判定基準そのものの適用範囲に関わる結果である。
- 結果は 1 つの環境と、こちらで設計したシフトに基づく。c のシフトは非常に強く、正解集合の大半は c だけで決まる。
