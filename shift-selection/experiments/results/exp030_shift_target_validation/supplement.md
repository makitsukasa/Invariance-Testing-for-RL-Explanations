## A. 状態の変換による AA と、ロールアウトの状態による AA の食い違い

### 何が食い違っていたか
exp030 は 2 種類の AA を記録している。

- aa：論文 A と同じ方法。学習時の評価状態の c 列を変換して計算する。判定に使う。
- aa_roll：シフトした環境でオラクルを走らせて得た状態で計算する。判定には使っていない。

c をシフトしたときの全 30 run の平均は次のとおりで、p = 0.0 と p ≥ 0.1 で大小が逆になる。

| p | aa（反転） | aa_roll（反転） | aa（ランダム化） | aa_roll（ランダム化） |
|---|---|---|---|---|
| 0.0 | 0.847 | 0.444 | 0.882 | 0.444 |
| 0.1 | 0.802 | 0.940 | 0.858 | 0.934 |
| 0.2 | 0.744 | 0.876 | 0.800 | 0.870 |
| 0.3 | 0.680 | 0.821 | 0.740 | 0.808 |

### 原因
環境では、c が示す角が本当のゴールでなければ、その角に着いてもエピソードは終わらない（`gridworld_env.py` の `step`。終わるのは本当のゴールに着いたときだけ）。c を反転すると、オラクルは c が示す角へ進み、そこで 100 ステップの上限まで留まる。p = 0 の反転で J_O が −1.000（= −0.01 × 100）になるのは、全エピソードがこの状態で時間切れになるためである。

再学習した 16 run（各 p で seed 0〜3）で、状態を「エージェントが c の示す角にいるか」で分けた。aa と aa_roll は、exp030 の記録と 64/64 で一致した。

| 条件 | p | 学習時の評価状態に占める「c の示す角」の割合 | ロールアウトの状態に占める割合 | aa_roll：角の状態 | aa_roll：それ以外 | aa |
|---|---|---|---|---|---|---|
| c 反転 | 0.0 | 0.000 | 0.963 | 0.400 | 0.919 | 0.825 |
| c 反転 | 0.1 | 0.322 | 0.482 | 0.907 | 0.987 | 0.839 |
| c 反転 | 0.2 | 0.335 | 0.428 | 0.903 | 0.902 | 0.720 |
| c 反転 | 0.3 | 0.438 | 0.519 | 0.825 | 0.874 | 0.680 |
| c ランダム化 | 0.0 | 0.000 | 0.928 | 0.365 | 0.924 | 0.868 |
| c ランダム化 | 0.1 | 0.322 | 0.460 | 0.885 | 0.974 | 0.876 |

この表から次のことが分かる。
- **p = 0 の aa_roll が低いのは、学習データに一度も現れない状態で測っているためである。** p = 0 では c は常に正しいので、c の示す角に着けばエピソードが終わる。そのため、その角にいる状態は学習データに 1 つもない（0.000）。ところが、c をシフトしたロールアウトでは、状態の 93〜96% がその角にいる。そこでの一致率は 0.37〜0.40 で、角以外の状態では 0.92 である。また、その角でのオラクルの行動は 4 方向に分散しており（上 0.23・下 0.29・左 0.36・右 0.13）、学習で決まった行動ではない。
- **p ≥ 0.1 で aa_roll が aa より高いのは、角の状態が学習データに含まれているためである。** 学習時にも確率 p で c が誤るので、角に留まる状態が学習データの 32〜44% を占める。サロゲートはそれを蒸留しているので、ロールアウトの状態でもよく一致する。
- **aa（状態の変換）は、学習分布の状態の位置を保ったまま c だけを変える。** 変換後の状態のうち、c の示す角にいるものは 0〜2%（ランダム化の p ≥ 0.1 では 16〜23%）である。

### どちらの AA が主張 1 の診断目的に対応するか
**主張 1 の判定の目的には、状態の変換による aa が対応する。** 論文 A の判定基準（`draft.md` 61 行目）は、「AA(D_shift) > θ_AA かつ J_S が崩壊」を「サロゲートがオラクルの行動を再現し続けているのに性能が崩れる、すなわち両者が同じスプリアス特徴に依存している」と読む。確かめたいのは、シフトした特徴が変わったときに、サロゲートがオラクルと同じように行動を変えるかである。aa は、学習分布の状態で c だけを変えてこれを直接測る。論文 A の実装（`experiments/run_gridworld.py` の `eval_states_for_condition`、コメント「c の効果だけを測定」）も、論文 A 実験 2 の値（AA = 0.942）もこの方法による。

aa_roll は別の量を測っている。シフトの結果としてオラクルが行き着く状態での一致率である。p = 0 では、その状態は両モデルとも学習していない領域にあり、一致率はそこでの任意の外挿の一致を反映する。サロゲートが c への依存を写し取っているかどうかとは関係しない。実際、p = 0 の c のシフトで、J_S と J_O はどちらも −1.000（反転）であり、両モデルの c への依存は一致しているのに、aa_roll は 0.44 だった。

ただし、次の 2 点は論文に書く必要がある。
1. 論文 A は AA(D) = E_{s∼D}[1[π_O(s) = π_S(s)]] と定義しており、D_shift がどの状態分布かを明記していない。字義どおりに読むとロールアウトの分布とも取れる。新しい草稿では、D_shift を「学習分布の状態にシフトを変換として適用した分布」と定義し、その理由（上の目的）を書く。
2. 状態の変換で書けないシフト（exp030 の開始位置の制限）では、aa もロールアウトの状態で測っている。この場合、シフト後の状態は学習分布の範囲内にあるので、上の問題は起きない（全 p で aa_roll(none) と AA(train) の差は 0.008 以下）。ただし、2 種類の測り方が混在していることは明記する。

### 判定を aa_roll に替えた場合（感度の確認。C）
段階 1 あり、Δ（サロゲート）、正解 = H_inv の場合：

| | 検出（全 120 run） | p = 0.0 | p = 0.1 | p = 0.2 | p = 0.3 | 誤警告（段階1 通過 51 run） |

| aa（主な結果） | 11 | 5 | 6 | 0 | 0 | 2 |

aa_roll に替えると、検出の総数は増える。一方で、スプリアス依存が最も強い p = 0 では、30 run 中 1 run しか検出されない。これは上の原因による。**手順全体の検出率は、AA の測り方の選択に強く依存する。** 主な結果は事前登録どおり aa のままとし、この感度は付録に載せる。

## B. p = 0.3 で Δ（サロゲート）が外れた原因

README では「限界はサロゲートの忠実度にある」と書いた。この帰属を確かめたところ、**AA で測った忠実度によるという根拠は得られなかった。** データと整合するのは、次の 2 つの要因である。

| p | モデル | Δ(c) 平均 | noise の Δ の SD | noise の Δ の run 内最大（平均） | c が top-1 | 環境で c を反転したときの低下 | 環境で c をランダム化したときの低下 |
|---|---|---|---|---|---|---|---|
| 0.0 | サロゲート | 0.540 | 0.002 | 0.002 | 30/30 | 1.969 | 1.051 |
| 0.0 | オラクル | 0.839 | 0.002 | 0.002 | 30/30 | 1.968 | 1.050 |
| 0.3 | サロゲート | 0.110 | 0.086 | 0.106 | 9/30 | 1.011 | 0.340 |
| 0.3 | オラクル | 0.273 | 0.076 | 0.110 | 21/30 | 1.063 | 0.357 |

（p = 0.1・0.2 を含む全体は `supplement.txt` の 1 節）

1. **AA(train) は当たり外れを分けない。** p = 0.3 で、Δ（サロゲート）の top-1 が c だった 9 run の AA(train) の平均は 0.811、そうでなかった 21 run では 0.800 だった（Mann–Whitney U、p = 0.47）。AA(train) と Δ_sur(c) の順位相関も弱い（ρ = +0.29、p = 0.13）。
2. **外れは Δ の推定のばらつきで説明できる。** noise の置換は U(0,1) を U(0,1) で置き換えるので分布が変わらず、noise の Δ の真の値は 0 である。観測された noise の Δ は、200 エピソードの推定のばらつきである（Δ は特徴ごとに別のエピソード seed を使い、共通乱数を使っていない）。そのばらつきは、リターンの分散が大きくなる p とともに広がる（SD は p = 0 で 0.002、p = 0.3 で 0.086）。p = 0.3 では、Δ_sur(c) の平均 0.110 が、7 個の noise の Δ の最大の平均 0.106 とほぼ同じ大きさになる。
3. **サロゲートの Δ(c) がオラクルより小さいのは、置換の値が c の取りうる値の外にあるためと考えられる。** 環境側で c を反転・ランダム化したときの低下は、どの p でもサロゲートとオラクルでほぼ同じである（p = 0.3 で 1.011 と 1.063、0.340 と 0.357）。つまり、c がとる値 {0, 1} の範囲では、両モデルの c への依存は同程度である。一方、Δ は c を連続値の U(0,1) で置き換える。この差は、AA も環境側のシフトへの反応も一致している p = 0 でも生じている（0.540 と 0.839）。したがって、サロゲートの Δ(c) が小さいのは、0 と 1 の間の値に対する 2 つのモデルの反応の違いと整合する。これは状況証拠であり、直接は確かめていない。

まとめ：p = 0.3 での限界は、AA で測ったサロゲートの近似精度には帰属できない。Δ の推定のばらつき（エピソード数、共通乱数なし）と、介入演算子が c を学習時の値の外に置くことの組み合わせと整合する。2 つ目を直接確かめるには、c を Bernoulli(0.5) で置き換え、共通乱数を使って Δ を計算し直す追加の実験が要る。120 run の再学習を含み、約 40〜50 分（4 並列）の見込みである。この実験はまだ行っていない。
