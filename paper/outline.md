# 統合した論文の構成案（研究1）

論文A（`draft.md`：不変性テスト）と論文B（`shift-selection/draft.md`：Δ によるシフト対象の選定）を、1 本の論文にまとめるための構成案です。本文はこの構成案の了承後に `paper/` に書きます。既存の草稿は変更しません。

## 主張

**「AA が高いサロゲートでも誤りうる。不変性テストで検出でき、シフトすべき特徴は Δ で選べる。」**

| | 主張1 | 主張2 |
|---|---|---|
| 主張 | AA が高いサロゲートでも、スプリアス依存を写し取っていることがあり、不変性テストで検出できる | どの特徴をシフトすべきかは、特徴ごとに介入したときの性能低下 Δ で選べる |
| 根拠 | GridWorld の reversed_c（論文A 実験2）、CartPole の物理パラメータシフト（論文A 実験3、対照） | GridWorld 10 次元の Δ（exp016 = exp029 のサロゲート Δ）、同じモデルでの Δ と SHAP の比較（exp029） |
| 正解の定義 | シフト後の性能崩壊（J_S） | Δ が選んだ特徴をシフトしたとき、実際に性能が崩壊するか |
| 言わないこと | スプリアス依存がないことの保証 | 候補特徴の自動発見（候補は低次元の状態特徴として与えられている前提）。Δ が一般に SHAP より優れていること |

主張2は 2026-10-25 に「SHAP では c がノイズと区別できない」を撤回した（`shift-selection/ERRATA.md`）。

## 判断が要る点（選択肢と推奨）

### 1. ColoredMNIST・Waterbirds を本文に入れるか
| 選択肢 | 長所 | 短所 |
|---|---|---|
| (a) 本文に入れる | 画像・実世界のスプリアス相関まで扱える | 論文の主題（RL の説明）から外れる。主張2の根拠は GridWorld だけで、画像では SHAP の検出率の方が高い（exp017 SHAP 120/120・Δ 102/120、exp018 SHAP 30/30・Δ 18/30）。ColoredMNIST の SHAP の集約には、コメントと実装の食い違い（2 クラス分の平均）が残っている |
| **(b) 付録に回す（推奨）** | 「Δ が一般に SHAP より優れているとは言わない」ことの根拠として、優劣の向きが設定によって変わることを示せる。本文は RL に絞れる | 付録が長くなる |
| (c) 外す | 論文が短く、主題が明確になる | 主張2の一般化の限界を示す材料を失う |

推奨は (b)。本文の 7 章で 1 段落だけ触れ、詳細は付録Bに置きます。ColoredMNIST の「構造的アーティファクト」の議論は、集約の食い違いの影響を確かめるまでは、付録でも断定しない書き方にします。

### 2. 候補発見の実験（shift-selection の exp023〜028）を使うか
| 選択肢 | 内容 |
|---|---|
| (a) 本文で使う | 「候補の自動発見」まで主張を広げることになり、主張2の「言わないこと」と食い違う |
| **(b) 一部だけ付録と限界で使う（推奨）** | GridWorld の exp023・024・027（linear_probe_drop などのプローブの drop）は、Δ とほぼ同じ量なので、付録Cで「Δ の亜種どうしの比較」として載せる。exp028（CLIP は背景、自己教師あり表現は前景を top-1 に選んだ）は、8 章で「候補の自動発見は解けていない」ことの根拠として引用する。exp025・026 は exp028 の予備として付録の脚注に留める |
| (c) 使わない | 候補発見が未解決であることの根拠を失う |

### 4. 日本語と英語のどちらを先に書くか
**推奨は日本語を先に書くこと。** 両方の草稿の全文が日本語であり、今回の訂正（SHAP の定義、集約の誤り、主張2の撤回）も日本語の草稿に対して整理しているためです。英語版は、投稿先が決まってから、その形式に合わせて書きます（投稿先の決定は今回の作業の範囲外）。

### 5. 主張2の「正解の定義」を満たす実験が足りていない
主張2の正解は「Δ が選んだ特徴をシフトしたとき、実際に性能が崩壊するか」ですが、今ある根拠は次の二つだけです。
- exp029：Δ が c を top-1 に置くか（c がスプリアスであることは環境の設計で既知）。
- exp005：Δ で選んだ後に Stage 2 で崩壊するか。ただし 5 シードで、Stage 2 は常に c を反転してテストしており、Δ が別の特徴を選んだときもその特徴ではなく c をシフトしている（exp005 の README に注記あり）。

| 選択肢 | 内容 |
|---|---|
| (a) 今ある結果で書く | exp029 の c の検出率を主な根拠とし、end-to-end は exp005（5 シード）で補う。正解の定義との差は限界に書く |
| **(b) 追加の実験をする（推奨）** | exp029 と同じ 120 run で、Δ が top-1 に選んだ特徴そのものをシフト（反転または置換）して J_S の崩壊を測る。exp029 と同じ設定なら 1 時間程度の見込み。実行する場合は、事前に実行時間を見積もって報告する |
