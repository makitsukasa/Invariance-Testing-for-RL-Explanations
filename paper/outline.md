# 統合した論文の構成案（研究1）

論文A（`draft.md`：不変性テスト）と論文B（`shift-selection/draft.md`：Δ によるシフト対象の選定）を、1 本の論文にまとめるための構成案です。本文はこの構成案の了承後に `paper/` に書きます。既存の草稿は変更しません。

## 主張

**「AA が高いサロゲートでも誤りうる。不変性テストで検出でき、シフトすべき特徴は Δ で選べる。」**

| | 主張1 | 主張2 |
|---|---|---|
| 主張 | AA が高いサロゲートでも、スプリアス依存を写し取っていることがあり、不変性テストで検出できる | どの特徴をシフトすべきかは、特徴ごとに介入したときの性能低下 Δ で選べる |
| 根拠 | GridWorld 3 次元の reversed_c（論文A 実験2）、CartPole の物理パラメータシフト（論文A 実験3、対照）。GridWorld 10 次元での判定条件の成否（exp030） | 選定と評価を独立させた検証（exp030：Δ で選んだ特徴を、置換ではなく環境側の分布シフトで評価）、同じモデルでの Δ と SHAP の比較（exp029・exp030） |

| 支持された範囲 | GridWorld 3 次元（論文A 実験2、10 シード）で、判定条件（AA(D_shift) > 0.9 かつ J_S の崩壊）が成り立つ。10 次元でも、成り立った run では誤警告は少ない（段階1 通過 51 run 中 2） | p ≤ 0.2 で、Δ（サロゲート）の top-1 が性能を崩す特徴に当たる割合はランダムを上回る（p = 0.0：30/30、0.1：29/30、0.2：18/29。ランダムの期待値は 3.0〜6.0）。同じモデル上で SHAP を上回る（p = 0.1・0.2）。事前登録した H1 は支持（87/117、期待値 21.6、Holm 補正後 p = 3e-44） |
| 確認できなかった範囲 | GridWorld 10 次元では、判定条件はほとんど成り立たない。c のシフト下の AA が 0.9 を割り（p = 0 で平均 0.85）、段階1（AA(train) ≥ 0.9）も 69/120 run が通過しない | p = 0.3 では、Δ（サロゲート）はランダムと区別できない（10/28、期待値 8.4）。原因は AA で測ったサロゲートの近似精度には帰属できず、Δ の推定のばらつきと、介入演算子が c を学習時の値の外に置くことの組み合わせと整合する（直接は未検証） |
| 言わないこと | スプリアス依存がないことの保証。判定条件が環境や特徴の数によらず成り立つこと | 候補特徴の自動発見（候補は低次元の状態特徴として与えられている前提）。Δ が一般に SHAP より優れていること。スプリアス相関が弱い場合（p = 0.3）の有効性 |

**主張1と主張2をつないだ診断手順全体（exp030 の H2）：** Δ（サロゲート）で選び、論文A の判定条件で判定する手順は、ランダムより多く検出した（11/120、ランダムの期待値 1.4、Holm 補正後 p = 1e-9。事前登録した H2 は支持）。ただし、検出率の絶対値は全 run の 9%（11/120）、段階1 を通過した run の 22%（11/51）にとどまる。妨げになっているのは選定ではなく判定条件である。補足として AA の条件を外すと、段階1 を通過した run の 94%（48/51）で検出する。本文では、ランダムを上回った事実と、絶対的な検出率が 11/120 にとどまった事実の両方を書く。

主張2は 2026-10-25 に「SHAP では c がノイズと区別できない」を撤回した（`shift-selection/ERRATA.md`）。

### 6. p = 0.3 の原因を確かめる追加の実験をするか
p = 0.3 で Δ（サロゲート）が外れたことは、「Δ の推定のばらつき」と「介入演算子が c を {0, 1} の外に置くこと」の組み合わせと整合するが、後者は直接確かめていない。
| 選択肢 | 内容 |
|---|---|
| **(a) 追加しない（推奨）** | 8 章に「p = 0.3 では確認できなかった。原因の候補は 2 つあり、直接は確かめていない」と書く。主張の範囲は変わらない |
| (b) 追加する | c を Bernoulli(0.5) で置き換え、共通乱数を使って Δ を計算し直す（120 run の再学習を含め約 40〜50 分、4 並列）。結果によらず、主張2の範囲（p ≤ 0.2）は事前登録どおりのままで、7・8 章の説明だけが変わる |

推奨は (a)。主張の範囲を決めるのは exp030 の事前登録した評価であり、原因の確認は論文の結論を変えないためです。

### 5. 主張2の「正解の定義」を満たす実験が足りていない
主張2の正解は「Δ が選んだ特徴をシフトしたとき、実際に性能が崩壊するか」ですが、今ある根拠は次の二つだけです。
- exp029：Δ が c を top-1 に置くか（c がスプリアスであることは環境の設計で既知）。
- exp005：Δ で選んだ後に Stage 2 で崩壊するか。ただし 5 シードで、Stage 2 は常に c を反転してテストしており、Δ が別の特徴を選んだときもその特徴ではなく c をシフトしている（exp005 の README に注記あり）。

| 選択肢 | 内容 |
|---|---|
| (a) 今ある結果で書く | exp029 の c の検出率を主な根拠とし、end-to-end は exp005（5 シード）で補う。正解の定義との差は限界に書く |
| (b) 追加の実験をする | exp029 と同じ 120 run で、Δ が top-1 に選んだ特徴そのものをシフト（反転または置換）して J_S の崩壊を測る |

**2026-10-25 の決定：** 選択肢 1〜4 は推奨どおり。5 は (b) の設計を修正する。Δ は置換による性能低下そのものなので、Δ で選んだ特徴に同じ介入をして確かめても検証にならない。選定と評価を独立させ、Δ・SHAP・ランダムを同じ条件で比較し、置換による性能低下と分布シフト下の不変性テストを区別し、主張1と主張2をつないだ手順全体も評価する。設計は `shift-selection/experiments/plans/exp030_shift_target_validation.md`（承認前は実行しない）。本文の執筆と main へのマージは、追加実験の結果と構成案の最終確認の後に行う。

**2026-10-26：** exp030 を実行した（120 run、exp029 と 120/120 で一致）。H1・H2 とも支持。結果は `shift-selection/experiments/results/exp030_shift_target_validation/`（README、stats.txt、補足分析は supplement.md）。結論として次を採用した。主張2は今回の条件で有効性が実測された。ただし p ≤ 0.2 で確認され、p = 0.3 では確認されなかった。手順全体はランダムを上回ったが、絶対的な検出率は 11/120 にとどまった。p = 0.3 の限界をサロゲートの近似精度に帰属することは、補足分析で根拠が得られなかったので書かない。
